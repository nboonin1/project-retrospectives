First post — mostly here to check that images, embedded video, and comments all work end to end.

## Images

Drop files in `assets/images/` and reference them with a normal relative path:

```markdown
![Alt text](/assets/images/example.png)
```

## Video

GitHub repos aren't built for hosting video (soft size limits, no streaming/scrubbing). Upload the
clip to YouTube (unlisted works fine for something that's mainly for you) and embed it:

```html
<iframe width="560" height="315"
        src="https://www.youtube.com/embed/VIDEO_ID"
        title="YouTube video player" frameborder="0" allowfullscreen>
</iframe>
```
